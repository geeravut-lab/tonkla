## 1. ความรู้สึกที่ต้องการ และแปลเป็นการออกแบบอย่างไร

เมื่อพนักงานเปิดระบบ ต้องรู้สึกว่า **ปลอดโปร่ง · ปลอดภัย · ไอเดียของฉันมีที่ไป**

| ความรู้สึก | แปลเป็น |
| --- | --- |
| **ปลอดโปร่ง** | พื้นหลังขาวอมเขียวมิ้นต์ `#F4FAF6` · ช่องไฟกว้าง · การ์ดมุมมน 16px เงานุ่ม · หนึ่งหน้า หนึ่งงานหลัก · ไม่มีตารางแน่นบนมือถือ |
| **ปลอดภัย** | เขียวเข้ม `#0E7A5C` น่าไว้ใจ · ป้ายบอกขอบเขตข้อมูลตรงจุดที่กรอก ("เห็นเฉพาะทีมของ บริษัท…") · ไม่ใช้แดงจัดกดดันผู้ใช้ (แดงเฉพาะลบ/ผิดพลาด + ไอคอน) · เห็นเสมอว่า **ใครเป็นเจ้าของเรื่อง และเหลือเวลาตอบกี่ชั่วโมง** |
| **นวัตกรรม/ไอเดีย** | สีส้มทอง "ประกายไอเดีย" `#FFB84D` ใช้เฉพาะจุดสำคัญ: ปุ่มเสนอไอเดีย · ตัวบอกขั้นประเมิน · รางวัล · จุดบนโลโก้ |
| **เป็นกันเอง ไม่ใช่ระบบราชการ** | ภาษาไทยเป็นกันเองแต่สุภาพ ("วันนี้อยากส่งเสียงเรื่องอะไร") · ภาพต้นกล้า/ใบไม้เป็นมอทิฟ (ใช้บน empty state และหน้าสำเร็จ) · ไม่ใช้รูปสต็อกคนใส่สูท |
| **ใช้ได้ทุกคน** | ตัวอักษร 16px ขึ้นไป · contrast ผ่าน AA · เป้าแตะ ≥ 44px · ใช้มือเดียวได้ (ปุ่มหลักอยู่ล่าง) |

## 2. โลโก้และ Favicon

เครื่องหมาย = **ต้นกล้าสองใบ** (ใบอ่อนสีเขียวอ่อน + ใบใหญ่สีขาวที่กำลังโต) บนลำต้นที่ก่อเป็นรูปตัว T พร้อม **จุดประกายสีส้มทอง** เหนือลำต้น (ไอเดียที่เพิ่งผลิ) บนป้ายมุมมนสีเขียวเข้ม

| ไฟล์ (`docs/design/`) | ใช้ | หมายเหตุ |
| --- | --- | --- |
| `tonkla-mark.svg` | เครื่องหมายเดี่ยว (header มือถือ, หน้า login) | มีจุดประกาย |
| `tonkla-logo-horizontal.svg` / `-dark.svg` | โลโก้เต็มแนวนอน "Tonkla / ต้นกล้า" พื้นสว่าง / พื้นมืด | ตัวอักษรแปลงเป็นเส้น (Geist 700 + Noto Sans Thai 600, shaped ด้วย HarfBuzz) ไม่พึ่งฟอนต์ |
| `favicon.svg` | Favicon แท็บเบราว์เซอร์ | **รุ่นง่าย**: ตัดจุดประกาย เส้นหนาขึ้น เพื่อให้อ่านออกที่ 16px |
| `favicon-32.png`, `favicon-48.png` | `<link rel="icon">` สำรองสำหรับเบราว์เซอร์ที่ไม่รับ SVG | |
| `apple-touch-icon.png` (180) | ไอคอนบนหน้าจอ iPhone | |
| `icon-192.png`, `icon-512.png` | PWA manifest | PNG จัตุรัสตามกฎ BRANDING |
| `icon-maskable.svg`, `icon-maskable-512.png` | Android ไอคอนวงกลม/สควิเคิล | เครื่องหมายอยู่ใน safe zone 80% |

**สีโลโก้:** ป้าย `#0E7A5C` · ใบอ่อน `#B8EBCF` · ใบใหญ่/ลำต้น `#FFFFFF` · ประกาย `#FFB84D` · ตัวอักษรพื้นสว่าง `#10282B` (รอง `#506468`)
**พื้นที่ว่างรอบโลโก้** ≥ ครึ่งความสูงของป้าย · ขนาดเล็กสุดของโลโก้เต็ม 120px กว้าง · ต่ำกว่านั้นใช้เครื่องหมายเดี่ยว
**ห้าม:** บีบ/เอียง/เปลี่ยนสี · วางบนพื้นที่ทำให้ความตัดกันของป้ายต่ำ · ใส่เงา

### 2.1 อัปโหลดเปลี่ยนโลโก้/ไอคอนได้ (R5, ตาม BRANDING-KNOWLEDGE)

- หน้า `/admin/brand`: ชื่อแอป (ไทย/อังกฤษ), โลโก้, ไอคอนแท็บ/ไอคอนติดตั้ง · ไม่อัปโหลด = ใช้ไฟล์ในตัวข้างบน
- รูปที่รับ: **PNG/JPEG/WebP เท่านั้น ตรวจชนิดจากไบต์** (ไม่รับ SVG/HTML) · ไอคอนต้องจัตุรัส 192–1024px
- เก็บใน bucket ส่วนตัว แต่เสิร์ฟสาธารณะผ่าน route ของเรา `/brand/logo`, `/brand/favicon` (หน้า login ต้องเห็นโลโก้) · อัปรูปใหม่ = ไฟล์ใหม่ + `version` ใหม่ใน URL (`?v=`) ไม่เขียนทับไฟล์เดิม
- ไม่มีรูปที่อัปโหลด = redirect ไปไฟล์ในตัว · ผลมีภายใน ~1 นาที (cache 30 วินาที — บอกบนหน้าจอ)
- ชื่อแอปเขียนในพจนานุกรมด้วยชื่อเริ่มต้นเสมอ แล้วสลับตอนอ่าน (`brandText`) ให้ถึงข้อความ LINE/อีเมล/AI · ห้าม `<img src="/logo.png">` ตรง ๆ ใช้ `LogoMark`
- `manifest.webmanifest` และ `<link rel="icon">` สร้างจากค่าที่ตั้ง (ไม่ใช่ไฟล์ static) · service worker ห้ามแคชข้อมูลส่วนตัว

## 3. Design tokens

hex อยู่ใน `theme.css` ไฟล์เดียว (lint `check-no-hex` กันที่อื่น) แล้วผูกเข้า Tailwind ด้วย `@theme inline`

```css
:root {
  --tk-bg:#F4FAF6; --tk-surface:#FFFFFF; --tk-ink:#10282B; --tk-muted:#506468;
  --tk-primary:#0E7A5C; --tk-primary-hover:#0A6149; --tk-primary-pressed:#084C3A;
  --tk-leaf:#5BC98F; --tk-sprout:#B8EBCF; --tk-sun:#FFB84D; --tk-mint:#DDF5E8;
  --tk-line:#DCE8E2; --tk-field-border:#6C8780;
  --tk-success-bg:#DDF5E8; --tk-success-fg:#0A6149;
  --tk-warning-bg:#FFE9B8; --tk-warning-fg:#10282B;
  --tk-danger-bg:#FDE4E1;  --tk-danger-fg:#B42318;
  --tk-info-bg:#E4EEF3;    --tk-info-fg:#1D4A5E;
  --tk-disabled-bg:#EDF2EF; --tk-disabled-fg:#7A8C88;
  --tk-shadow:0 1px 2px rgb(16 40 43/.06),0 6px 20px rgb(16 40 43/.07);
  --radius-card:16px; --radius-control:12px;
}
```

**Contrast ที่คำนวณแล้ว** (WCAG; สคริปต์อยู่ใน PR ของ M1.1 เป็นเทสอัตโนมัติ)

| ข้อความ / พื้น | อัตราส่วน |
| --- | --- |
| ink / bg · ink / surface | 14.6 · 15.4 |
| muted / bg · muted / surface | 5.9 · 6.2 |
| ขาว / primary (ปุ่มหลัก) | 5.3 |
| primary / surface · primary / bg | 5.3 · 5.0 |
| primary-hover / mint (เมนูที่เลือก) | 6.5 |
| ink / sun · ink / leaf · ink / sprout | 9.0 · 7.5 · 11.6 |
| danger-fg / danger-bg | 5.4 |
| field-border / surface (ขอบช่องกรอก) | 3.9 (≥ 3:1) |

**กฎ:** ห้ามตัวอักษรขาวบน `leaf`/`sun` (2.1 / 1.7) · ข้อความบนพื้น `leaf`/`sun`/`sprout` ใช้ `ink` · ข้อความ `primary` บน `mint` ใช้ `primary-hover` · `line` ใช้ตกแต่งเท่านั้น (1.26:1) · สถานะต้องมีไอคอน/ข้อความกำกับ ไม่สื่อด้วยสีอย่างเดียว

**สัดส่วนสี:** พื้นอ่อน (`bg` `surface` `mint`) ≈ 70% · เขียว (`primary` `leaf`) ≈ 22% · ส้มทอง ≈ 8%

**โหมดมืด:** ไม่อยู่ในเฟส 1 (ออกแบบ token ให้สลับได้ภายหลัง — ตั้งชื่อตามบทบาท ไม่ตามสี)

## 4. ตัวอักษร

- **Noto Sans Thai** (ไทย) + **Geist** (ละติน/ตัวเลข) ฝังจาก bundle ผ่าน `@fontsource-variable/*` ไม่เรียก Google Fonts · stack: `Geist → Noto Sans Thai → ui-sans-serif, system-ui`
- สเกลที่ใช้: 12 · 14 · 16 · 18 · 20 · 24 · 30 · 36 px · น้ำหนัก 400/500/600/700
- เนื้อหา ปุ่ม ช่องกรอก = **16px** (กัน iOS ซูม) · คำอธิบาย 14px · ป้ายเมนูล่าง 12px (บรรทัดเดียว)
- ระยะบรรทัดฐาน **1.6** · ข้อความไทยหลายบรรทัดห้าม `leading-none`/`tight` (สระวรรณยุกต์ซ้อน)
- ตัวเลขจำนวน/ยอด/ชั่วโมงคงเหลือ ใช้ `tabular-nums`

## 6. รูปแบบเฉพาะของ Tonkla

### 6.1 การ์ดเรื่อง (ปัญหา/ไอเดีย) — "ฉันต้องรู้ 3 อย่างเสมอ"
ทุกเรื่องแสดงในที่เดียวกัน: **(1) สถานะ** เป็นป้ายมีไอคอน (2) **ผู้รับผิดชอบ** (อวาตาร์ + ชื่อ) (3) **เวลาที่เหลือก่อนครบกำหนดตอบ** เป็นแถบ + ตัวเลข ("เหลือ 31 ชม. จาก 48") — เกินกำหนดเปลี่ยนเป็นป้าย `⚠ เกินกำหนดตอบ` (ข้อความ+ไอคอน ไม่ใช่สีอย่างเดียว) · ป้าย "อัปเดตสด" (จุดเขียวเต้น) บอกว่าหน้ากำลังรับสถานะแบบ live

### 6.2 ฟอร์ม
สั้น เรียงตามความสำคัญ: เกิดอะไรขึ้น → ส่งผลอย่างไร → แนบรูป (ปุ่ม "ถ่ายรูป" เปิดกล้องตรง) → วิธีแก้ที่เสนอ (ไม่บังคับ) · แถบ "เห็นเฉพาะ…" ด้านบน · ปุ่มส่งติดขอบล่าง · ย่อรูปฝั่งเครื่องก่อนอัปโหลด · ฟอร์มไม่ถูก refresh ใต้มือจาก live sync · เก็บร่างอัตโนมัติ

### 6.3 ตัวหมุนโหลด (R9)
`<PendingButton>`: กดแล้วแสดงวงกลมหมุนทันทีซ้ายข้อความ · ข้อความเปลี่ยนเป็น "กำลัง…" · `aria-busy`/`disabled` กันกดซ้ำ · หายเองเมื่อเสร็จหรือพัง · เมนู/ลิงก์ใช้ `<PendingLink>` แสดงตัวหมุนที่รายการที่กดจนหน้าใหม่พร้อม · เปลี่ยนหน้าแสดงแถบบางที่ขอบบน · ตัวหมุนเคารพ `prefers-reduced-motion` (ช้าลง ไม่หายไป) · ดูตัวอย่างใน brand-preview ส่วน "ตัวหมุนโหลด"

### 6.4 สถานะว่าง / ผิดพลาด / สำเร็จ
ว่าง: ภาพต้นกล้า + ประโยคชวนทำ ("ยังไม่มีเรื่อง — มีอะไรอยากส่งเสียงไหม") · ผิดพลาด: ประโยคที่คนอ่านรู้เรื่อง + ปุ่มลองใหม่ (ไม่โชว์รหัส) · สำเร็จ: ข้อความบอกขั้นถัดไปและใครจะตอบเมื่อไร ("ส่งแล้ว — คุณสมชายจะตอบภายใน 48 ชั่วโมง")

### 6.5 ข้อความ
ไทยก่อน อังกฤษสลับได้ (cookie + โปรไฟล์) · ทุกข้อความผ่าน `dict.ts` · น้ำเสียง: อบอุ่น ตรงไปตรงมา ไม่ตำหนิ · ข้อความของคำปฏิเสธเรื่อง/ไอเดียต้องมีเหตุผลเสมอ

## 7. การ์ดแจ้งเตือน LINE (Flex) — ปรับสีให้เข้ากับ Tonkla

โครงตาม LINE-FLEX-CARD-KNOWLEDGE (bubble ใบเดียว: หัวเรื่อง → ≤8 บรรทัด `ป้าย: ค่า` → ปุ่ม) เปลี่ยนเฉพาะสี

| ส่วน | สี |
| --- | --- |
| หัวเรื่อง | `#0A6149` (primary-hover — contrast สูงบนขาว) |
| ข้อความ | `#10282B` · ป้ายรอง `#506468` |
| ปุ่มหลัก "เปิดแอป" | พื้น `#0E7A5C` (primary) — ปุ่ม Flex แบบ primary กำหนดสีพื้นได้แต่ป้ายบนปุ่มเป็นสีขาวตายตัว จึงต้องใช้พื้นเข้ม (ขาวบน primary 5.3:1) · **ไม่ใช้ `sun`** (ขาวบน sun แค่ 1.7:1) · ยืนยันบนเครื่องจริง iOS/Android |
| `altText` | รายละเอียดครบ ≤ 400 ตัวอักษร (เห็นบนหน้าจอล็อก) |

ชนิดการ์ด (เฟส 1): ได้รับเรื่องแล้ว · ถูกมอบหมายให้คุณ · ใกล้ครบกำหนดตอบ · เกินกำหนด (ถึงหัวหน้า/ผู้ประสานงาน) · สถานะเรื่องของคุณเปลี่ยน · ประกาศต้องอ่าน · ไอเดียเปลี่ยนระยะ · ผลการนำไปใช้ · **ไม่มีเนื้อหาละเอียดของเรื่องร้องเรียน/ข้อมูลอ่อนไหว** — บอกแค่ว่ามีเรื่อง ให้เปิดแอป

## 8. การทดสอบ UX ที่เป็นเกณฑ์ผ่าน

1. Playwright ที่ **390×844** แล้ว **1280×800** ทุกหน้าใน §5 · `scrollWidth ≤ clientWidth` · axe ไม่มี violation ร้ายแรง
2. spinner: หน่วงเครือข่าย → เห็นตัวหมุน → กดซ้ำไม่ได้ (นับ request = 1) → เสร็จแล้วตัวหมุนหาย · ทั้งปุ่มฟอร์มและเมนู
3. contrast ของ token ทุกคู่ตาม §3 (เทสอัตโนมัติ)
4. i18n: key ไทย/อังกฤษตรงกัน · placeholder `{name}` ตรงกันทั้งสองภาษา
5. Back: ทุกหน้าลึกมี BackLink · ปุ่ม Back ของเครื่องปิดแผ่น "เพิ่มเติม" แล้วอยู่หน้าเดิม
6. เครื่องจริง: iPhone Safari (PWA และเบราว์เซอร์), Android Chrome, เบราว์เซอร์ในแอป LINE, เดสก์ท็อป Chrome/Edge
7. ตรวจด้วยผู้ใช้จริง 3–5 คนจากบริษัทนำร่อง: ส่งเรื่องแรกได้ภายใน 1 นาทีโดยไม่ต้องสอน
