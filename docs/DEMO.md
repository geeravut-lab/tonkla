- รูปประกอบเป็นภาพวาดประกอบ (ไม่ใช่ภาพถ่ายจริง) แนบกับรายงานปัญหา 7 เรื่อง

## องค์กร (7 บริษัท ใน 4 กลุ่มธุรกิจ)

| กลุ่มธุรกิจ | บริษัท (รหัส) |
| --- | --- |
| กลุ่มอุตสาหกรรมอาหารและบรรจุภัณฑ์ | ต้นกล้า ฟู้ดส์ (`food`), ต้นกล้า แพคเกจจิ้ง (`pack`) |
| กลุ่มค้าปลีกและโลจิสติกส์ | ต้นกล้า รีเทล (`retail`), ต้นกล้า โลจิสติกส์ (`logi`) |
| กลุ่มเทคโนโลยีและสุขภาพ | ต้นกล้า เทค (`tech`), ต้นกล้า เฮลท์แคร์ (`health`) |
| สำนักงานกลาง | ต้นกล้า โฮลดิ้ง (`hq`) |

## บัญชี (32 บัญชี)

| บัญชี | บทบาท | เห็นอะไรเป็นพิเศษ |
| --- | --- | --- |
| `owner.group` | เจ้าของกลุ่ม | ภาพรวมทั้งกลุ่ม |
| `central.team1`, `central.team2` | ทีมกลาง | ทุกบริษัท, Dashboard กลุ่ม, มอบรางวัลประจำปี, สร้างชุมชน/โจทย์/กิจกรรมระดับกลุ่ม (`team1` เป็นผู้จัดการเรื่องร้องเรียนไม่ระบุตัวตน) |
| `admin.system` | ผู้ดูแลระบบ | ตั้งค่าระบบ, สวิตช์ฟีเจอร์, รอบการขยาย, audit, อีเมล/LINE/AI |
| `coordinator.<บริษัท>` | ผู้ประสานงานบริษัท | รับเรื่อง/ย้ายสถานะ, เปิดไอเดียให้ทั้งกลุ่ม, งบทดลอง, มอบรางวัล (ทั้ง 6 บริษัท) |
| `exec.food`, `exec.retail`, `exec.tech` | ผู้บริหารบริษัท | Dashboard บริษัท, ยืนยันผลลัพธ์ (คนที่สอง), อนุมัติงบ |
| `supervisor.<บริษัท>` | หัวหน้างาน | ปิดเรื่องเล็กได้ทันที (quick fix) |
| `employee1.<บริษัท>`, `employee2.<บริษัท>` | พนักงาน | แจ้งปัญหา เสนอไอเดีย โหวต ตอบโพล ถามผู้บริหาร |
| `pending.newcomer` | ผู้สมัครใหม่ที่ยังไม่ได้รับอนุมัติ | แสดงขั้นตอนเข้าร่วมบริษัท (ยังไม่ยอมรับประกาศความเป็นส่วนตัว) |

บัญชีสาธิตยอมรับประกาศความเป็นส่วนตัวไว้แล้ว ยกเว้น `pending.newcomer`

## ข้อมูลที่มี (เกิดจากการใช้งานจริง 107 รายการ)

ประกาศกลุ่ม (ต้องรับทราบ) + ประกาศบริษัท · รายงานปัญหา 7 เรื่องพร้อมรูป (ครบทุกสถานะ: แก้แล้ว, ปิดเร็วโดยหัวหน้างาน, รับเรื่อง, กำลังดำเนินการ) · แนวปฏิบัติที่ดีที่สร้างอัตโนมัติ 3 รายการ · ไอเดีย 8 เรื่อง (ครบทุกระยะ รวม "ถูกปฏิเสธ" และ "นำไปใช้ที่บริษัทอื่น") · ผลลัพธ์ที่ยืนยันแล้ว (ประหยัด 48,000 บาท, ลดเวลา 120 ชม.) · งบทดลอง 15,000 บาท (อนุมัติแล้ว ใช้ไป 9,800) · ทีมข้ามบริษัท · โจทย์ท้าทาย · กิจกรรม 2 รายการ + ตอบรับ · โพล · ถามตอบผู้บริหาร (มีคำถามแบบซ่อนชื่อ) · เหตุฉุกเฉิน 1 เรื่อง · เรื่องร้องเรียนไม่ระบุตัวตน 2 เรื่อง · เอกสารคลังความรู้ 2 ฉบับ · ชุมชนการเงินและไอที · รางวัลผลงานเด่น, "กล้าลอง" และรางวัลประจำปี

## เส้นทางนำเสนอที่แนะนำ (ประมาณ 20 นาที)

1. **พนักงาน** `employee1.food`: หน้าแรก → แจ้งปัญหา (กด "ให้ AI แนะนำหมวด") → ดูรายงานสายพานพร้อมรูปและความคืบหน้า → เสนอไอเดีย → ถามจากคลังความรู้ ("ลาป่วยต้องแจ้งกี่โมง")
2. **ผู้ประสานงาน** `coordinator.food`: งานผู้ประสานงาน → รับเรื่อง/ปิดเรื่อง → ไอเดีย QR Code เดินครบ 5 ระยะ ผลลัพธ์ยืนยันโดยผู้บริหาร → Dashboard บริษัท (สรุปรายสัปดาห์ด้วย AI)
3. **ผู้บริหาร** `exec.food`: Dashboard บริษัท และการยืนยันผลลัพธ์
4. **ทีมกลาง** `central.team1`: ภาพรวมทั้งกลุ่ม (เทียบกลุ่มธุรกิจ, ส่งออก CSV) → ผลงานเด่นและรางวัลประจำปี → เรื่องร้องเรียนไม่ระบุตัวตน (เห็นเฉพาะทีมกลางที่ถูกแต่งตั้ง) → ชุมชนตามสายงาน
5. **ผู้ดูแลระบบ** `admin.system`: รอบการขยาย, สวิตช์ฟีเจอร์, audit trail, ตั้งค่า AI/อีเมล/LINE

เมนูฟีเจอร์ใหม่ (ฉุกเฉิน, ถามตอบ, ปฏิทิน, โพล, โจทย์, คลังไอเดีย, ผลงานเด่น, คลังความรู้, ทีมร่วม, งบทดลอง, ชุมชน, ร้องเรียน) อยู่ใน "เพิ่มเติม" บนมือถือ

## หมายเหตุ

- ผู้ให้บริการ AI: เครดิต Anthropic หมด (400 "credit balance is too low") ระบบจึงสลับไปใช้ Google Gemini สำรองอัตโนมัติ เติมเครดิตที่ Anthropic เพื่อใช้ Claude ตามที่ตั้งไว้เป็นหลัก
- เรื่องร้องเรียนไม่ระบุตัวตนที่สร้างไว้: รหัสเรื่องและรหัสลับถูกแสดงตอนรันสคริปต์ครั้งเดียว ใช้ทดสอบหน้า `/anonymous/status` ได้เมื่อสร้างเรื่องใหม่ผ่านหน้าเว็บ
